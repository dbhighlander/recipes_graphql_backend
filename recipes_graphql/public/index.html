GraphQL API Documentation

Explore your API using the GraphQL Playground or via POST requests

Endpoint

The GraphQL endpoint is:

POST /graphql

Authentication

Mutations or queries marked with requires auth require a Bearer token in the Authorization header:

Authorization: Bearer <your-token-here>

Sample Queries

1. Get current user (requires auth)


query {
  me {
    id
    email
  }
}

2. Get all recipes (requires auth)


query {
  recipes {
    data {
      _id
      title
      description
      author {
        id
        email
      }
    }
    error
  }
}

Sample Mutations

1. Create a new user


mutation {
  createUser(email: "test@example.com", password: "StrongPass123!") {
    token
    error
  }
}

2. Login


mutation {
  login(email: "test@example.com", password: "StrongPass123!") {
    token
    error
  }
}

3. Create a recipe (requires auth)


mutation {
  createRecipe(title: "Spaghetti Bolognese", description: "Classic Italian pasta with meat sauce") {
    data {
      _id
      title
      description
      author {
        id
        email
      }
    }
    error
  }
}

Notes

  • Ensure your password is strong when creating a user.
  • All mutations and queries marked requires auth need authentication.
